# Tray Icon Assets

This directory contains the tray icons for different application states:

## Icon States

- **tray-inactive.png** - Hollow moon symbol (gray) - No active sleep prevention
- **tray-active.png** - Filled sun symbol (orange) - Currently preventing sleep  
- **tray-expired.png** - Checkmark symbol (green) - Prevention session completed

## Design Requirements

- **Size**: 16x16 points (32x32 pixels for retina)
- **Format**: PNG with transparency
- **Style**: Monochrome template images for macOS system tray
- **Guidelines**: Follow Apple Human Interface Guidelines for menu bar icons
